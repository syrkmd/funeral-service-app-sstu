# Funeral Service App

Веб-приложение для оформления ритуальных услуг с административной панелью.

---

## Архитектура проекта

frontend/   — клиентская часть (React + Vite)
backend/    — серверная часть (в разработке)
proxy/      — прокси-сервер (в разработке)
db/         — база данных (в разработке)

---

## Frontend (React)

Клиентская часть приложения.

### Функциональность

* Многошаговое оформление заказа
* Выбор услуг и товаров
* Личный кабинет по номеру телефона
* Админ-панель:

  * просмотр заказов
  * изменение статусов
  * управление оплатой
  * работа с документами
  * мониторинг (RPS, активность)
  * управление IP и rate limiting (интерфейс)

### Запуск

cd frontend
npm install
npm run dev

Приложение доступно по адресу:
http://localhost:5173
